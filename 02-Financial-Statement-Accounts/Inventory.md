# Inventory

## ความหมาย

สินค้าที่กิจการถือไว้เพื่อขายหรือใช้ในการผลิต

## ความเสี่ยง

- นับจำนวนผิด
- สินค้าล้าสมัย
- ตีมูลค่าผิด

## วิธีตรวจสอบ

- Stock Count
- Test Count
- NRV Testing
- Cut-off Testing

## หลักฐาน

- Stock Card
- Inventory Report
- Purchase Invoice

## สิ่งที่ควรจำ

Assertion ที่สำคัญคือ Existence และ Valuation
