# Audit Program

## ความหมาย

Audit Program คือ แผนการตรวจสอบที่ระบุขั้นตอน วิธีการ และขอบเขตของงานตรวจสอบในแต่ละบัญชี

## ประโยชน์

- ช่วยวางแผนงาน
- กำหนดขั้นตอนการตรวจสอบ
- ใช้ติดตามความคืบหน้าของงาน

## ตัวอย่าง

บัญชีเงินสด

- ขอ Bank Confirmation
- ตรวจ Bank Reconciliation
- ตรวจสอบรายการหลังวันสิ้นงวด

## สิ่งที่ควรจำ

Audit Program เป็นคู่มือการทำงานของผู้สอบบัญชีในแต่ละบัญชี
